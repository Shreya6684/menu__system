# 🍔 Simple Menu System (Java)

Hey there! 👋 Welcome to the **Simple Menu System**, a straightforward Java console application designed to simulate an interactive food and drink ordering menu right inside your terminal. 

This project was built to practice foundational Java concepts like control flow, nested logic, and reading user input cleanly.

---

## 🌟 What It Does

* **Category Selection:** Main menu that splits options between **Food** and **Drinks**.
* **Nested Sub-Menus:** 
  * Select **Food** to choose between **Pizza** ($12.99) and **Burger** ($8.99).
  * Select **Drinks** to choose between **Coffee** ($4.50) and **Juice** ($3.99).
* **Price & Order Summary:** Instantly outputs your selection alongside its cost.
* **Error Handling:** Gracefully handles invalid numeric entries at both category and sub-menu levels with clear feedback.

---

## 🛠️ Built With

* **Language:** Java
* **Core Concepts Used:** 
  * `java.util.Scanner` for interactive terminal input
  * Nested `switch-case` blocks for clean decision-making
